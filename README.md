## Built with
- HTML and CSS
- Vanilla JavaScript (no frameworks)
- Noroff API
- Figma (style guide and design)
- GitHub Projects (planning)
- GitHub Pages (hosting)
  
## Pages
- Home – product carousel and product grid (/index.html)
- Product – details for one product (/product/index.html)
- Login (/account/login.html)
- Register (/account/register.html)
- Cart (/cart/index.html)
- Checkout (/checkout/index.html)
- Success – order confirmation (/success/index.html)
